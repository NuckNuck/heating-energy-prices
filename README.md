# Heizenergiepreise für Home Assistant

Home-Assistant-Integration, die aktuelle Brennstoffpreise für Heizsysteme (Heizöl, Erdgas, Holzpellets, Fernwärme)
aus amtlichen und Verbandsquellen als Sensoren bereitstellt – für Wärmekosten-Vergleiche, z. B. im
[Luft-Wasser-Wärmepumpen-Audit](https://github.com/NuckNuck/air-water-heatpump-audit).

Die Integration entsteht gerade; Details folgen mit der ersten Version.
